SkillSpector: ein kostenloser Scanner, der KI-Erweiterungen prüft, bevor Sie sie installieren

SicherheitDatenschutzKI-Agenten

Ihr KI-Assistent lernt neue Tricks über Erweiterungen: fertige Anweisungspakete, die ihm beibringen, Offerten zu entwerfen, Dateien zu lesen oder in Ihrem Ton zu antworten. Praktisch — und ein bisschen wie Software von einem Fremden zu installieren. Ein kostenloser Scanner von NVIDIA sieht sich solche Erweiterungen jetzt an, bevor Sie sie installieren.

Was ein “Skill” eigentlich ist

Werkzeuge wie Claude Code, Codex oder Gemini CLI laden kleine Pakete, sogenannte Skills. Ein Skill ist meist eine Textdatei mit Anweisungen, manchmal mit kleinen Skripten dazu. Er zeigt Ihrer KI, wie eine Aufgabe zu erledigen ist — und läuft in der Regel mit Zugriff auf das, was der Assistent sehen kann: Dateien, eingefügten Text, manchmal das Netzwerk.

Die meisten Skills stammen von öffentlichen Marktplätzen und Plattformen. Viele sind nützlich und harmlos. Aber eine Erweiterung, die lesen kann, was Ihre KI liest, verdient einen zweiten Blick.

Die unangenehmen Zahlen

SkillSpector basiert auf einer Studie, die 42'447 Skills von grossen Marktplätzen untersuchte. Das Ergebnis: 26,1 Prozent enthielten mindestens eine Sicherheitslücke, 5,2 Prozent zeigten Anzeichen einer möglicherweise böswilligen Absicht. Skills mit ausführbaren Skripten waren mehr als doppelt so oft problematisch.

Zwei Gefahren sind für ein Büro am wichtigsten:

  • Versteckte Anweisungen: ein Skill kann Befehle enthalten, denen Ihre KI folgt, ohne es Ihnen zu zeigen — etwa “ignoriere die bisherigen Regeln” oder Anweisungen, die in Kommentaren versteckt sind.
  • Stille Datenlecks: ein Skill kann Inhalte nach aussen senden — Text aus Ihren Dateien, gespeicherte Passwörter, Dateipfade — an eine Adresse, die Sie nie gewählt haben.

Wenn Ihr Assistent Mandantendokumente öffnen kann, kann eine schlampig gemachte Erweiterung das auch.

Was der Scanner tut

SkillSpector, von NVIDIA als Open Source (Apache 2.0) veröffentlicht, prüft einen Skill vor der Installation. Sie zeigen ihm einen Link, einen Ordner oder eine Zip-Datei — er arbeitet in zwei Durchgängen:

  • Erster Durchgang: schnelle statische Kontrollen gegen 64 bekannte Schadensmuster in 16 Kategorien — versteckte Anweisungen, Datenlecks, Lieferketten-Tricks, übermässige Berechtigungen — plus eine Live-Abfrage der verwendeten Bausteine gegen eine öffentliche Datenbank bekannter Schwachstellen.
  • Zweiter Durchgang (optional): ein KI-Modell liest die markierten Stellen im Zusammenhang und sortiert Fehlalarme aus. Dieser Durchgang kann gegen ein lokales Modell wie Ollama laufen — die Prüfung selbst schickt dann nichts in eine Cloud.

Das Ergebnis ist eine Risikobewertung von 0 bis 100, eine Einstufung des Schweregrads und ein Bericht, der auf die genaue Zeile hinter jedem Fund zeigt — damit Ihre IT-Fachkraft selbst beurteilen kann, statt einer Zahl zu vertrauen.

Was das für ein Schweizer Kleinunternehmen bedeutet

Sie müssen den Scanner nicht selbst bedienen, um die Lehre ernst zu nehmen. Nach dem revidierten schweizerischen Datenschutzgesetz bleiben Sie verantwortlich für Mandantendaten, die Ihre Werkzeuge berühren — ein Leck durch eine “hilfreiche” Erweiterung ist trotzdem Ihr Leck. Ein paar Gewohnheiten decken den grössten Teil des Risikos ab:

  1. Installieren Sie KI-Erweiterungen nur aus Quellen, die Sie benennen können.
  2. Fragen Sie, was eine Erweiterung lesen darf, bevor sie an Mandantenakten kommt.
  3. Lassen Sie neue Erweiterungen prüfen — mit SkillSpector oder von der Person, die Ihre IT betreut.
  4. Halten Sie Mandantendaten von ungeprüften Werkzeugen fern.

Ehrliche Grenzen: Eine Prüfung ist eine Momentaufnahme, keine Garantie — sie analysiert Code, nicht das Verhalten zur Laufzeit, und sie kann Text in Bildern nicht lesen. Und das Werkzeug ist konkret für Agenten-Skills gebaut; wenn Sie solche Erweiterungen nie installieren, zählt die Gewohnheit mehr als das Werkzeug. Der Komfort von Klick-und-fertig-Erweiterungen ist real. Die Verantwortung, die dazukommt, auch.
