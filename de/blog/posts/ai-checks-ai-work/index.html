Eine zweite KI, die die erste prüft: Fehler erkennen, bevor Sie senden

KI-AgentenKorrekturlesenQualität

KI kann heute Ihre E-Mails, Rechnungen und Offerten in Sekunden entwerfen — macht dabei aber still und leise Fehler. Die neuesten Werkzeuge setzen auf einen klugen Trick: eine zweite KI, die die Arbeit der ersten noch einmal liest und Fehler markiert, bevor Sie sie überhaupt bemerken. Was diese Idee “KI beobachtet KI” für ein kleines Schweizer Büro bedeutet und wie Sie sie schon heute mit Ihren vorhandenen Werkzeugen nutzen, lesen Sie hier.

Der Fehler, den niemand bemerkt

Bitten Sie eine KI, eine Zahlungserinnerung oder einen Kundenbrief zu schreiben, und sie klingt überzeugend — selbst wenn sie falsch liegt. Sie kann eine Zahl erfinden, zwei Kunden verwechseln oder einen Mehrwertsteuersatz falsch runden. Weil der Text glatt klingt, versteckt sich der Fehler in aller Deutlichkeit. Für einen Notar, einen Arzt oder eine Treuhänderin ist eine falsche Zahl in einem Brief genau die kleine Panne, die still Vertrauen kostet.

Menschen übersehen solche Fehler, weil sie nur überfliegen. Und dieselbe KI, die den Text geschrieben hat, übersieht sie meist ebenfalls — sie ist ja überzeugt, richtig zu liegen. Genau dieses Problem wollen die neuesten Werkzeuge lösen.

Eine zweite KI als Korrekturleserin

Die Idee ist einfach: Eine KI schreibt, eine andere prüft. Anthropic hat kürzlich in seinem Programmier-Assistenten Claude Code eine Funktion namens “You Should Know” ergänzt — ein kleiner Helfer, der jeden Schritt des Haupt-Assistenten beobachtet und auf das hinweist, was man sonst überlesen würde. Sie richtet sich an Programmierer, aber das Prinzip lässt sich direkt ins Büro übertragen.

Im Alltag ist das die “Vier-Augen-Regel”, die Ihre Kanzlei längst kennt. Eine Person schreibt den Brief, eine zweite liest ihn, bevor er hinausgeht. Genau diese zweite Meinung bekommen Sie jetzt für alles, was eine KI entwirft — ohne eine zweite Person einzustellen.

So geht es mit dem, was Sie schon haben

Sie brauchen weder Claude Code noch neue Software. Das Muster funktioniert mit zwei gewöhnlichen Chats:

  1. Öffnen Sie ChatGPT oder Claude und lassen Sie sich die Rechnung, E-Mail oder Offerte entwerfen.
  2. Öffnen Sie ein zweites Gespräch — oder gleich ein anderes Werkzeug — und fügen Sie den Entwurf dort ein.
  3. Sagen Sie: “Du bist eine sorgfältige Korrektorin. Finde jede falsche Zahl, jeden falschen Namen, jeden unklaren Satz und jede Behauptung, die nicht belegt ist. Schreibe nichts um, liste nur auf, was falsch ist.”

Dieser zweite Durchgang fängt die meisten Fehler in unter einer Minute ab. Er kostet nichts extra und funktioniert auf Deutsch, Französisch und Englisch. Speichern Sie die Anweisung einmal ab — daraus wird eine Zehn-Sekunden-Gewohnheit, bevor etwas Wichtiges hinausgeht.

Was sie nicht behebt

Eine KI-Prüferin ist ein Sicherheitsnetz, keine Garantie. Sie kann einen feinen Fehler übersehen und kann Ihnen nicht sagen, ob eine Zahl wahr ist — nur, ob sie in sich stimmig ist. Die letzte Kontrolle bleibt also bei Ihnen: Lesen Sie den Entwurf einmal selbst, mit der Liste der KI daneben.

Das ist die ehrliche, nüchterne Version. Zwei KIs fangen deutlich mehr ab als eine, und keine ersetzt Ihr eigenes Urteil. Aber für den Preis eines zweiten Einfügens ist es eines der einfachsten Sicherheitsnetze, das ein Schweizer Büro in diesem Monat einbauen kann.
