Hermes Agent

Hermes Agent ist ein quelloffener KI-Agent von Nous Research, gebaut um eine Idee: ein Agent, der mit dir wächst. Er lernt aus Erfahrung — speichert, was funktioniert, als wiederverwendbare Skills — und behält ein bleibendes Gedächtnis darüber, wer du bist und wie du arbeitest.

Was Hermes Agent ist

Hermes wurde im Februar 2026 veröffentlicht und läuft in deinem Terminal, einer nativen Desktop-App, deinen Messaging-Plattformen und IDEs. Es ist anbieterunabhängig — es funktioniert mit über 20 Modell-Anbietern, einschliesslich lokaler Modelle — und schottet die Aktionen, die es ausführt, in Sandboxen ab.

Sein prägendes Merkmal ist die Lernschleife: Wenn Hermes ein Problem gut löst, kann es den Ansatz als Skill speichern und beim nächsten Mal wiederverwenden. Über Wochen baut es so eine Bibliothek darüber auf, wie dein Betrieb läuft — ein spürbar anderes Erlebnis als ein zustandsloser Chatbot.

Was es gut kann

🔄

Lernschleife

Erstellt Skills aus Erfahrung und verbessert sie im Einsatz — je mehr du es nutzt, desto fähiger wird es.

🧠

Bleibendes Gedächtnis

Merkt sich Vorlieben, Projekte und frühere Lösungen, mit austauschbaren Gedächtnis-Backends.

🌐

Multi-Plattform-Gateway

Ein Agent, ein Gedächtnis, über Telegram, Discord, Slack, WhatsApp, Signal, E-Mail und mehr.

🖥️

Viele Oberflächen

CLI, Terminal-UI, native Desktop-App, Web-Übersichtsseite und IDE-Integration.

🔀

Anbieterunabhängig

Modelle und Anbieter mitten im Ablauf wechseln; Zugangsdaten über mehrere Schlüssel rotieren.

🛡️

Isolierte Sandboxen

Fünf Backends — lokal, Docker, SSH, Singularity, Modal — mit Container-Härtung.

So kommst du dazu

Installiere über einen Shell-Installer und starte dann den Einrichtungs-Assistenten, um Modell und Anbieter zu wählen:

Terminal
# macOS / Linux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows (PowerShell)
irm https://hermes-agent.nousresearch.com/install.ps1 | iex

# Interaktiver Chat / Einrichtungs-Assistent
hermes
hermes setup

Hermes bringt ausserdem eine native Desktop-App für macOS, Windows und Linux mit, falls du eine grafische Oberfläche dem Terminal vorziehst. Wie bei OpenClaw ist der praktische Weg für viele Betriebe eine betreute Einrichtung — konfiguriert, abgeschottet und verbunden für dich, dann einfach vom Handy oder Desktop aus genutzt.

Sicherheit & Kontrolle

Hermes ist mit Blick auf Kontrolle gebaut: abgeschottete Ausführungs-Backends, Geheimnis-Schwärzung, Freigabe-Modi und Profile, die verschiedene Kontexte (Arbeit, privat) getrennt halten. Die native Unterstützung lokaler Modelle bedeutet, dass du die Denkarbeit auf deiner eigenen Hardware laufen lassen kannst, wenn deine Datenschutz-Anforderungen es verlangen.

Warum lokale Modelle hier zählen. Ein selbst gehosteter Agent ruft üblicherweise trotzdem ein gehostetes Modell (Claude, GPT …) über eine API auf. Hermes lässt dich das gegen ein offenes Modell tauschen, das auf deiner eigenen Hardware läuft — eine wertvolle Option, wenn Kundendaten deine Räumlichkeiten nie verlassen dürfen.
