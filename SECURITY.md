# Security

This repository contains **no credentials**.

## ⚠️ Credential rotation required

The `hermesbackup` snapshot this tooling was recovered from contained live credentials in plaintext `.env` files. Those files were **excluded** here, but the values must be treated as **compromised** and rotated. See the rotation table in the `facturio` repository's `SECURITY.md`.

## Reporting a vulnerability

Email **security@strongwinds.ch**.
