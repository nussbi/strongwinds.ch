Jev : une IA qui lit le climat avant que vous répondiez

Communication clientProtection des donnéesProductivité

Un message client délicat arrive sur WhatsApp. Vous le lisez deux fois sans savoir s’il est agacé ou simplement pressé. C’est exactement pour ce moment qu’existe Jev, une application gratuite et open source. Elle lit la conversation, évalue le ton et le risque, puis vous propose des réponses toutes prêtes — classées selon ce jugement. L’envoi reste votre geste.

Ce que Jev fait concrètement

La plupart des aides d’écriture IA fonctionnent à l’envers : vous demandez un texte, la machine le rédige. Jev commence une étape plus tôt, par un jugement. Avant la moindre ébauche, l’application lit la conversation visible et pose trois questions discrètes : que veut vraiment cette personne ? Le moment est-il délicat ? Comment bien répondre ?

C’est seulement ensuite que Jev rédige. Vous recevez plusieurs propositions, classées et accordées à cette lecture. Un geste, et le texte se place dans votre champ de saisie, prêt à être corrigé. Jev n’envoie jamais seul.

Sur Android, l’application s’affiche par-dessus WhatsApp (et aussi X, QQ et Feishu). Des versions Windows et macOS lisent la fenêtre de chat par captures d’écran et reconnaissance de texte sur l’appareil.

Les limites honnêtes

Jev est un logiciel jeune qui demande des accès étendus. Avant l’installation, sachez ceci :

  • La prise en charge de WhatsApp est une préversion v0.1.0 — balbutiante, et cela se voit.
  • Il n’existe pas d’application iPhone sur l’App Store : sous iOS, il faudrait compiler le clavier vous-même.
  • Pour lire une conversation, l’application utilise des accès puissants : le service d’accessibilité Android, ou captures d’écran et reconnaissance de texte sur ordinateur.
  • Vos textes partent vers le fournisseur de modèle dont vous saisissez la clé API. Le projet n’exploite aucun serveur — mais les mots quittent quand même votre appareil.
  • L’application est gratuite sous licence MIT ; chaque jugement coûte ce que votre fournisseur de modèle facture par requête.

Les chiffres avancés viennent du projet lui-même ; aucun test indépendant n’existe encore.

Ce que cela signifie pour la confidentialité

Quand on est indépendant en Suisse, l’historique WhatsApp vaut souvent un demi-dossier client : noms, adresses, échéances, prix, parfois des détails de santé ou juridiques. La révision de la loi suisse sur la protection des données n’interdit pas les assistants IA. Elle vous rend simplement responsable de ce qui quitte vos appareils — et du soin avec lequel vous choisissez outils et fournisseurs.

La vraie question n’est donc pas “a-t-on le droit ?” mais : “quelles conversations l’application peut-elle voir, et où voyagent-elles ?” Traitez le fournisseur de modèle comme tout autre sous-traitant : quelle société est-ce, où traite-t-elle le texte, ses conditions permettent-elles un entraînement sur vos données ?

Un choix de conception mérite un éloge : Jev rédige, vous envoyez. Une ébauche dans le champ de saisie est une suggestion, pas une divulgation. Le moment sensible se joue plus tôt, à la lecture de la conversation. C’est cette étape qu’il faut peser — pas le bouton d’envoi.

Comment l’essayer sereinement

  1. Récupérez l’application Android, Windows ou macOS depuis la page GitHub Releases du projet — le code est ouvert, chacun peut le lire.
  2. Utilisez une clé API d’un fournisseur que vous avez vérifié — ou un que vous employez déjà.
  3. Testez sur une conversation sans données client : votre second téléphone, un groupe familial, une collègue.
  4. Gardez une règle : Jev propose, vous décidez. Si un fil contient ce que vous ne transféreriez pas à un inconnu, répondez sans assistance.

Pour les moments clients tendus, une seconde lecture du climat sert vraiment — gardez simplement le choix de ce qui quitte votre téléphone entre vos mains.
